# 3D Utilities

A collection of small, single-purpose, parametric 3D-modeling utilities for 3D printing and milling — containers, jigs, fixtures, and similar objects.

Each utility is written as Python code with [build123d](https://build123d.readthedocs.io/), exported as STEP geometry into `manufacture/`, and manufactured from that STEP file with a slicer (for 3D printing) or a CAM tool (for milling). Because models are code, dimensions are ordinary parameters: a utility is regenerated by editing its source and re-running it, never redrawn by hand.

Repository layout:

| Path | Purpose |
|------|---------|
| `src/<utility_name>/` | One directory per utility: the utility's parametric modeling code plus its `README.md`. |
| `src/scaffold/` | Grandfathered placeholder package: the pre-convention home of the older modeling code, left as-is. |
| `manufacture/` | Generated STEP files (gitignored). |
| `resources/modeling/` | Reusable modeling knowledge: jigs, screws, brackets, snap fits, and general techniques. |
| `memory-bank/` | Living project records: brief, requirements, design, plans, and stories. |

New utilities are added as their own `src/<utility_name>/` directory, containing the utility's source code and a `README.md`. The existing `src/scaffold/` package is grandfathered: it keeps the utilities that predate this convention and receives no new ones.

See [GETTINGSTARTED.md](GETTINGSTARTED.md) for environment setup, testing, and viewing models.
