# 3D Utilities

A collection of small, single-purpose, parametric 3D-modeling utilities for 3D printing and milling — containers, jigs, fixtures, and similar objects.

Each utility is written as Python code with [build123d](https://build123d.readthedocs.io/), exported as STEP geometry into `manufacture/`, and manufactured from that STEP file with a slicer (for 3D printing) or a CAM tool (for milling). Because models are code, dimensions are ordinary parameters: a utility is regenerated by editing its module and re-running it, never redrawn by hand.

Repository layout:

| Path | Purpose |
|------|---------|
| `src/scaffold/` | Parametric modeling code, one module per utility. |
| `manufacture/` | Generated STEP files (gitignored). |
| `resources/modeling/` | Reusable modeling knowledge: jigs, screws, brackets, snap fits, and general techniques. |
| `memory-bank/` | Living project records: brief, requirements, design, plans, and stories. |

See [GETTINGSTARTED.md](GETTINGSTARTED.md) for environment setup, testing, and viewing models.
