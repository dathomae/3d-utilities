# Terms

Specific names and phrases used in the project. Add one row per term with its definition.

| Term | Definition |
|------|------------|
| build123d | The Python CAD library used to define all geometry in this repository. |
| STEP | ISO 10303 file format (`.step`/`.stp`) that stores exact boundary-representation geometry and is the interchange format between modeling and manufacturing. |
| slicer | Software that converts a model into the layers/tool paths for a 3D printer. |
| CAM | Computer-aided manufacturing software that converts a model into tool paths for subtractive machining (milling). |
| M5 | A metric machine screw with a 5 mm major diameter; the standardized mounting screw for the vertical mill bed. |
| clearance hole | A hole sized so a screw's shank passes through freely (larger than the threads). |
| countersink / counterbore | Recesses that let a screw head sit flush (countersink, conical) or below (counterbore, cylindrical) the surface. |
| workholding | The practice of securing a workpiece on a machine, for example by clamping or by bolting a jig to the mill bed. |
